## 📌 Project Overview

Designed and developed a relational database for a banking loan management system using SQL. The project demonstrates database design, normalization, table relationships, and SQL operations to efficiently manage customers, loan applications, loan approvals, repayments, and branch information.

---

## 🎯 Project Objectives

- Design a normalized banking database
- Manage customer and loan records
- Track loan approvals and repayments
- Maintain data integrity with constraints
- Practice SQL DDL and DML operations

---

## 🛠 Technologies Used

- SQL
- MySQL
- Relational Database Management System (RDBMS)
